# Eval run 2026-10-06, full baseline

Every case of both apps, three times each, on master after 0.4.0 (`bfbfd75`). This run
is the baseline in `eval/baseline/summary.json` that later runs are compared with
(`eval/compare.sh`, see docs/eval.md "When to run it").

Compared with the earlier runs of the same cases (2026-10-05 SQL and MongoDB runs,
2026-10-06 new cases): no regression. Two cases went up, both because of changes since:
`idem-dedup-outside-transaction` 1 of 3 to 3 of 3 (rebuilt so the removed guard is the
only one) and `tx-nested-payout-email` 2 of 3 to 3 of 3 (findings now carry `code`, so a
finding the model put on line 1 moves to its line).

The one false alarm is the same as in the first run of the new cases: RACE-6 low, "the
daily limit counts only the current batch". It holds only if the job runs more than
once a day, which the case does not say; it stays counted as a false alarm.

`clean-avatar-upload` and `mongo-clean-relay-batch` are skipped by triage, as before:
neither change touches money, and Claude is not started.
